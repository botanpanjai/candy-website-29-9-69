⚠️ แอปพลิเคชันไม่ตอบสนอง

หากใช้คำสั่งของ Candy Bot แล้วขึ้นข้อความ แอปพลิเคชันไม่ตอบสนอง โดยทั่วไปหมายถึงบอทไม่ได้ตอบ Interaction ภายในเวลาที่ Discord กำหนด

🔧 วิธีแก้ไข

  1. ตรวจสอบว่า Candy Bot ยังออนไลน์อยู่หรือไม่
  2. ลองใช้คำสั่งใหม่อีกครั้ง
  3. ตรวจสอบว่า Bot มีสิทธิ์ใช้งานในห้องนั้น
  4. ตรวจสอบ Permission ของ Bot ใน Server
  5. หากเกิดเฉพาะบางคำสั่ง อาจเป็นปัญหาที่ระบบของคำสั่งนั้น
💡 หากลองใหม่แล้วยังไม่หาย ให้รอสักครู่แล้วลองใช้คำสั่งอีกครั้ง

🔴 บอทออฟไลน์

หาก Candy Bot แสดงสถานะ Offline หรือไม่สามารถใช้งานคำสั่งต่าง ๆ ได้ ให้ตรวจสอบตามขั้นตอนด้านล่าง

🔧 วิธีแก้ไข

  1. ตรวจสอบว่า Candy Bot ยังอยู่ในเซิร์ฟเวอร์หรือไม่
  2. ตรวจสอบสถานะของบอท
  3. ลองเชิญ Bot เข้า Server ใหม่หากบอทถูกนำออก
  4. ตรวจสอบว่า Discord ไม่มีปัญหาขัดข้อง
⚠️ หากบอทออฟไลน์พร้อมกันหลายเซิร์ฟเวอร์ อาจเป็นปัญหาจากระบบของ Candy Bot

⚙️ ใช้คำสั่งไม่ได้

หาก Slash Command ไม่ทำงานหรือไม่พบคำสั่งที่ต้องการ ให้ลองตรวจสอบการตั้งค่าของ Discord Server

🔧 วิธีแก้ไข

  1. ตรวจสอบว่า Candy Bot ออนไลน์
  2. ตรวจสอบว่า Bot มีสิทธิ์ใช้งานคำสั่ง
  3. ตรวจสอบว่า Discord แสดง Slash Command ของ Candy Bot หรือไม่
  4. ลองออกจาก Discord แล้วเข้าใหม่
  5. ลองพิมพ์ชื่อคำสั่งใหม่อีกครั้ง
💡 หากเพิ่งเพิ่ม Bot เข้า Server อาจต้องรอสักครู่เพื่อให้คำสั่งแสดงผล

🎭 รับยศไม่ได้

หากกดปุ่มรับยศแล้ว Candy Bot ไม่สามารถมอบ Role ให้ได้ ปัญหาส่วนใหญ่มักเกิดจาก Permission หรือระดับของ Role

🔧 วิธีแก้ไข

  1. เข้า Server Settings
  2. ไปที่เมนู Roles
  3. ตรวจสอบ Role ของ Candy Bot
  4. เลื่อน Role ของ Candy Bot ให้อยู่สูงกว่า Role ที่ต้องการแจก
  5. ตรวจสอบว่า Bot มี Permission Manage Roles
⚠️ Discord ไม่อนุญาตให้ Bot มอบ Role ที่อยู่สูงกว่าหรือเท่ากับ Role สูงสุดของ Bot

✅ ยืนยันตัวตนแล้วไม่ได้ยศ

หากกดปุ่มยืนยันตัวตนสำเร็จ แต่ยังไม่ได้รับ Role ให้ตรวจสอบการตั้งค่าระบบ Verify

🔧 วิธีแก้ไข

  1. ตรวจสอบว่า Role สำหรับสมาชิกยังมีอยู่
  2. ตรวจสอบว่า Role ไม่ได้ถูกลบหรือเปลี่ยนชื่อ
  3. ตรวจสอบลำดับ Role ของ Candy Bot
  4. ตรวจสอบว่า Candy Bot มี Permission Manage Roles
  5. ลองตั้งค่าระบบ Verify ใหม่
✅ หาก Role อยู่ต่ำกว่า Role ของ Bot และ Bot มี Manage Roles ระบบควรสามารถมอบ Role ได้

🎫 เปิด Ticket ไม่ได้

หากกดปุ่มเปิด Ticket แล้วไม่มีอะไรเกิดขึ้น ให้ตรวจสอบ Permission และการตั้งค่าระบบ Ticket

🔧 วิธีแก้ไข

  1. ตรวจสอบว่า Candy Bot ออนไลน์
  2. ตรวจสอบว่า Bot มี Permission ใน Category Ticket
  3. ตรวจสอบว่า Bot สามารถสร้าง Channel ได้
  4. ตรวจสอบ Permission Manage Channels
  5. ตรวจสอบว่าระบบ Ticket ถูกตั้งค่าไว้แล้ว
💡 หากกดปุ่มแล้วไม่มีข้อความตอบกลับ อาจเกี่ยวข้องกับ Permission หรือระบบ Ticket ของบอท
